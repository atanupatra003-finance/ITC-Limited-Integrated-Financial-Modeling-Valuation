# ITC Limited – Integrated Financial Modeling & Valuation

## Project Overview

This project presents an integrated financial model and valuation analysis of **ITC Limited**, an Indian diversified conglomerate. The model is designed to evaluate the company's historical financial performance, forecast future financial results, assess financial health, and estimate its intrinsic value using multiple valuation methodologies.

The workbook covers five years of historical financial performance and five years of projected financials, incorporating key financial statements, valuation techniques, and investment analysis.

## Key Features & Model Components

### 1. Company Overview & Investment Outlook
- Company profile, business overview, and investment outlook.
- Summary of key financial performance indicators and investment considerations.

### 2. Forecasting Assumptions & Methodology
- Key revenue, expense, profitability, and working capital assumptions.
- Explanation of assumptions used to forecast future financial performance.

### 3. Financial Statements
- Historical and projected Income Statement.
- Balance Sheet analysis.
- Cash Flow Statement.

### 4. Financial Analysis
- Financial ratio analysis covering profitability, liquidity, leverage, and efficiency.
- Common-size Income Statement and Balance Sheet.
- DuPont Analysis to evaluate Return on Equity (ROE) and Return on Assets (ROA).

### 5. Cost of Capital Analysis
- Beta analysis using regression methodology.
- Weighted Average Cost of Capital (WACC) calculation.

### 6. Valuation Analysis
- Discounted Cash Flow (DCF) valuation to estimate intrinsic equity value.
- Comparable Company Analysis using peer valuation multiples.
- Football Field Analysis to compare valuation outcomes across methodologies.

### 7. Company Snapshot & Financial Summary
- Key financial metrics and performance indicators.
- Consolidated overview of financial performance and valuation outputs.

## AI Integration & Assistance

AI tools were used as supporting resources during the development of this project for:
- Understanding financial modeling concepts and valuation methodologies.
- Supporting the development and review of Excel formulas.
- Assisting with financial analysis, model structure, and presentation.
- Improving the clarity of assumptions, interpretations, and project documentation.

**Note:** AI was used as an assistance tool. Financial assumptions, model calculations, and valuation outputs should be independently reviewed and verified.

## Tools & Technologies
- **Microsoft Excel:** Financial modeling, forecasting, financial analysis, and valuation.
- **AI-Assisted Tools:** Research support, formula guidance, analytical assistance, and documentation.
- **Financial Methodologies:** DCF, WACC, Comparable Company Analysis, Beta Regression, and DuPont Analysis.

## Project Objective

The primary objective of this project is to develop practical skills in financial statement analysis, integrated financial modeling, forecasting, corporate valuation, and investment analysis while demonstrating the application of financial concepts through a real-world publicly listed company.

This project is prepared for educational and analytical purposes only. It does not constitute investment advice or a recommendation to buy or sell ITC Limited securities.
